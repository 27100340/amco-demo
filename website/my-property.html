Drawing guide for architects

What we need

One floor plan for each floor, a section drawing for every section marked on the plans, a working drawing for each section, and the site layout. PDFs, scans and photos are fine too: you trace the walls over them in the review step.

Save as DXF

We can't read DWG files in the browser. In AutoCAD use File, Save As, and choose a DXF type (AutoCAD R12 or 2000 and later, not binary). Keep everything in model space, not only on a layout sheet.

Units

Draw in millimetres and set the drawing units ($INSUNITS) to millimetres if you can. If the file doesn't say, we work out the units from the wall thickness, because 9″ and 4½″ walls are standard. You can change the units in the review step.

Titles and tags

Write the title on each sheet: GROUND FLOOR PLAN, FIRST FLOOR PLAN, SECTION A-A, WORKING DRAWING SECTION A-A, SITE LAYOUT (or SITE PLAN). Tag every door and window (D1, W1, V1) and list them in the schedule on the working drawings, for example "D1 DOOR 1050 x 2100". Mark levels on sections as "FFL +3.350", "CEILING +3.050" or "PARAPET +7.750".
